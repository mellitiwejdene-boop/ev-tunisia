# EV Tunisia

Application web de localisation et de gestion des bornes de recharge pour voitures électriques en Tunisie, développée avec React JS (Vite) et React-Leaflet.

## Fonctionnalités

- Page d'accueil et page principale
- Carte interactive des bornes (`map()`)
- Liste des bornes avec leurs caractéristiques (`map()`)
- Recherche par nom ou ville et filtre de disponibilité (`filter()`)
- Statistiques du réseau (`reduce()`)

## Lancer le projet

    npm install
    npm run dev

Puis ouvrir http://localhost:5173
